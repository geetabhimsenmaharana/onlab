A way to find information by comparing vectors and looking for the closest matches.

01

THE IDEA

What is Vector Search?

Vector Search is a way of finding information by comparing numerical representations called vectors.

Instead of looking only for the exact words in a question, vector search looks for vectors that are mathematically similar.

This makes it useful when we want to find information that has a similar meaning, even when the exact words are different.

02

A SIMPLE EXAMPLE

Imagine a map.

Imagine that every piece of information has a location on a giant map.

A user asks:

"How can I generate electricity from sunlight?"

The system searches the vector space for information located close to the question.

"Solar panels convert sunlight into electricity."

The words are different, but the ideas are closely related.

How it works.

User Question

The question is converted into an embedding.

The query vector is compared with stored vectors.

04
Return Matches

04

THE MATH

How do we know what is close?

Vector search uses mathematical similarity measures to compare vectors.

01

Cosine Similarity

Compares the angle between two vectors.

02

Distance

Measures how far apart two vectors are in vector space.

03

Similarity Score

A numerical value can indicate how closely two vectors match.

04

Top Results

The system can return the closest matching pieces of information.

Where does it fit?

In a RAG system, vector search helps retrieve relevant information before the LLM generates its answer.

01

02
