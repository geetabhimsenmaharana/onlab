GENERATIVE AI 02

Understanding
Embeddings.

A way to represent text, images, or other information as numbers so a computer can work with their meaning and relationships.

01

THE IDEA

What is an embedding?

An embedding is a numerical representation of information. A piece of text, for example, can be converted into a list of numbers called a vector.

The numbers themselves do not have a simple human-readable meaning. Instead, the vector represents patterns and relationships learned by the embedding model.

This allows a computer to compare pieces of information based on how similar their representations are.

02

A SIMPLE EXAMPLE

Think of it like a map.

Imagine putting every word or sentence on a giant map. Information with similar meaning can appear closer together, while information with different meaning can appear farther apart.

01
King

A word describing a type of person.

02
Queen

Related to the concept of king.

03
Pizza

A very different concept.

In a real embedding space, these relationships are represented using many numerical dimensions.

03

BEHIND THE SCENES

How does text become numbers?

01

Text

We start with a word, sentence, paragraph, or document.

02

Embedding Model

The embedding model processes the input and creates a numerical representation.

03

Vector

The result is a list of numbers representing the input.

04

Comparison

Vectors can be compared to find information with similar meaning.

For example:

"Solar panels produce electricity."

The embedding model converts this sentence into a vector containing many numbers.

A simplified example might look like:

[0.24, -0.18, 0.76, 0.45, ...]

Real embedding vectors usually contain hundreds or thousands of dimensions.

04

WHY IT MATTERS

Why do we need embeddings?

Computers work very well with numbers. By converting information into vectors, we can use mathematical methods to compare and search large amounts of information.

01

Semantic Search

Find information based on meaning, not just exact keywords.

02

Recommendations

Find items that are similar to something a user already likes.

03

RAG

Find relevant documents before generating an AI response.

04

Clustering

Group information that has similar patterns or characteristics.

05

EMBEDDINGS + RAG

Where does it fit in RAG?

Embeddings are one of the important building blocks of a RAG system.

01
Document

A document is split into smaller pieces called chunks.

02
Embedding

Each chunk is converted into a vector.

03
Vector Database

The vectors are stored for searching.

04
Search

A user's question is compared with stored vectors to find relevant content.

06

What I understand so far.

An embedding converts information into a numerical representation called a vector.

Similar meaning can be represented by vectors that are closer together in the embedding space.

Embeddings make it possible to search and compare information using mathematical similarity.

In RAG, embeddings help the system find relevant information before the LLM generates an answer.
