GENERATIVE AI 06

Prompt
Engineering.

The practice of designing clear instructions that help an AI model produce useful and consistent results.

01

THE IDEA

What is Prompt Engineering?

A prompt is the instruction or input we give to an AI model.

Prompt Engineering is the practice of designing that instruction carefully so the model has enough information to understand the task.

A prompt can include the task, context, examples, constraints, and the format we want in the answer.

02

A SIMPLE EXAMPLE

Be clear about the task.

Imagine asking an AI:

"Tell me about solar energy."

The model has many possible ways to answer.

We can make the request more specific:

"Explain how solar panels generate electricity in five simple bullet points for a beginner."

The second prompt gives the model more information about the task and the expected output.

03

PROMPT STRUCTURE

What can a prompt contain?

01

Role

Provides guidance about how the model should approach the task.

02

Task

Clearly explains what the model needs to do.

03

Context

Gives the model useful background information.

04

Output Format

Describes how the final response should be structured.

04

PROMPT ANATOMY

Putting the pieces together.

Role: You are a data analyst.

Task: Analyze the following sales data.

Context: The data contains monthly sales from January to December.

Constraint: Identify the three largest changes.

Output: Return the result as a simple table.

Instead of giving the model one short sentence, we provide the information it needs to perform the task more clearly.

05

TECHNIQUES

What I'm learning.

01

Zero-Shot

Ask the model to perform a task without providing examples.

02

Few-Shot

Provide examples that show the model what the desired output looks like.

03

Constraints

Define boundaries such as length, format, audience, or required content.

04

Iteration

Test the prompt, evaluate the result, and improve the instruction.

06

BEHIND THE SCENES

What happens after I send a prompt?

01
Prompt

The user provides an instruction and optional context.

02
Tokens

The input is processed as tokens that the model can work with.

03
Model

The model processes the input and predicts an appropriate continuation.

04
Output

The model generates the response based on the input and its learned patterns.

07

PRACTICAL EXAMPLE

From vague to specific.

Suppose I want an AI to explain a Python concept.

Vague:

"Explain Python dictionaries."

More specific:

"Explain Python dictionaries to a beginner. Use a simple real-world analogy, show one basic Python example, and explain the example line by line."

The second prompt gives the model more direction about the audience, explanation style, and output.

08

IMPORTANT IDEA

Prompting is an iterative process.

01
Write

Create the first version of the prompt.

02
Test

Run the prompt and examine the output.

03
Evaluate

Check whether the result meets the goal.

04
Improve

Change the prompt and test again.

09

MY NOTES

What I understand so far.

A prompt is the instruction or input given to an AI model.

Prompt Engineering is about designing clear and useful instructions.

Context, examples, constraints, and output format can make a prompt more specific.

Different prompts can produce different outputs from the same model.

Prompting is often an iterative process: write, test, evaluate, and improve.
