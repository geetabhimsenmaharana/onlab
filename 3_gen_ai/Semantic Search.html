GENERATIVE AI 04

Semantic
Search.

A way to search for information based on meaning, not only on the exact words in a query.

01

THE IDEA

What is Semantic Search?

Traditional search often looks for matching words or keywords.

Semantic Search tries to understand the meaning behind a query and find information that is related to that meaning.

Embeddings and vector search are commonly used to support this type of search.

02

A SIMPLE EXAMPLE

Keywords vs. meaning.

Imagine searching a company knowledge base with this question:

"How do I reset my password?"

01

Keyword Search

Looks for matching words such as "reset" and "password".

02

Semantic Search

Can find related wording such as "change my login credentials".

03

BEHIND THE SCENES

What happens behind the scenes?

01
User Query

02
Embedding

The query is converted into a vector.

03
Vector Search

The query vector is compared with stored vectors.

04
Relevant Results

Results related to the query are returned.

04

AN IMPORTANT CONNECTION

Embeddings, vectors, and search.

01

Embedding

Converts information into a numerical representation.

02

Vector

The list of numbers produced by an embedding model.

03

Vector Search

Compares vectors to find similar information.

04

Semantic Search

Uses these techniques to search based on meaning and relationships.

05

SEMANTIC SEARCH + RAG

Why is it useful for RAG?

A RAG system needs to retrieve useful information before asking an LLM to generate an answer.

Semantic search can help retrieve relevant information even when the user's wording does not exactly match the wording in the documents.
