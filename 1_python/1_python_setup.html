PYTHON 01

Setting up
Python.

A simple guide to checking Python, installing Python on a Mac, setting up Visual Studio Code, and running your first Python program.

01

FIRST STEP

Is Python already installed?

Before installing Python, check whether Python is already available on your Mac.

Open Terminal and run:

Command 

  python3 --version

If Python is installed, you should see something similar to: 

  Python 3.14.6

Your version may be different. That is okay. The important thing is that Python responds with a version number.

02

CODE EDITOR

Is Visual Studio Code installed?

Visual Studio Code, commonly called VS Code, is a code editor where you can write and run Python programs.

To check whether the VS Code command is available in Terminal, run: 

  code --version

If it is configured correctly, Terminal will show the VS Code version.

For example: 

  1.105.1

If you see: 

  zsh: command not found: code

VS Code may still be installed. It simply means that the code command is not available in your Terminal yet.

03

INSTALLATION

Installing Python on Mac.

If Python is not installed, download the latest Python installer for macOS from the official Python website.

Open the downloaded installer and follow the installation steps.

01

Download

Download the Python installer for macOS.

02

Install

Open the installer and follow the installation instructions.

03

Restart Terminal

Close and reopen Terminal after the installation.

04

Check Again

Run the Python version command to verify the installation.

04

VERIFY THE SETUP

Does Python actually work?

Checking the version tells us Python is installed. We can go one step further and actually run Python.

01
Open Terminal

Open Terminal on your Mac.

02
Start Python

Run python3.

03
Python Prompt

You should see the >>> prompt.

04
Run Code

Type print("Hello, Python!") and press Enter.

You should see: 

  Hello, Python!

To leave the Python interpreter, run: 

  exit()
05

FIRST PROGRAM

Create your first Python file.

Now let's create a small Python program.

01

Create a File

Create a new file called hello.py.

02

Write Code

Add a simple print statement.

03

Save

Save the file as hello.py.

04

Run

Run the program from Terminal.

Your Python code: 

  print("Hello, world!")

Run it from Terminal with: 

  python3 hello.py

The result should be: 

  Hello, world!
